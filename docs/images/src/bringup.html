장치 초기화와 수신 순서

USB를 꽂은 순간부터 TS가 나오기까지 드라이버가 하는 일 (Windows 드라이버 분석 + 실측)

1연결 (cold)USB core
  • FX2 부트 ROM 상태
  • iManufacturer = 0 → COLD
  • EEPROM은 VID/PID만 보유
2FX2 펌웨어 업로드download_firmware
  • vendor req 0xA0: CPUCS=1 → RAM 16 KB → CPUCS=0
  • 재연결: Manufacturer "SKYDIGITAL" → WARM
3전원 · 리셋 (GPIO)read_config
  • PD6=1 튜너 전원, PD1=1 튜너 리셋 해제
  • PD7 0→1 복조기 리셋
  • I2C에 0x61, 0x59가 나타남
4프론트엔드 연결frontend/tuner_attach
  • lgdt3305_attach (LGDT3304)
  • xc5000_attach (IF 6000 kHz)
  • ops 래핑: init, set_frontend
↓
5frontend 열기init
  • LGDT3304 init 테이블 + soft reset
  • sleep 후 AGC·ADC 복구 (보정 ③)
6XC5000 펌웨어xc5000
  • dvb-fe-xc5000-1.6.114.fw I2C 로드
  • RESET → 콜백으로 PD1 펄스
  • 61바이트 초과 쓰기는 주소 헤더 반복 분할
7튜닝set_frontend
  • XC5000: DTV6 (video 0x8002 / audio 0x00C0), IF 6 MHz
  • LGDT3304: VSB + NCO=0, TP_CTRL_1=0x1b (보정 ①②)
8스트림streaming_ctrl
  • 36 03 00 01 (내부 IFCLK) 시작
  • EP2 bulk → dvr0
  • ATSC 19,392,658 b/s
